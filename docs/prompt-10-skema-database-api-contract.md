# 10/ Skema Database & API Contract

> Berperanlah sebagai Lead Backend Engineer. Berdasarkan PRD, rancang arsitektur data dan API contract yang efisien dan scalable.
>
> Hasilkan:
> * Entity Relationship Diagram (ERD): Daftar tabel, kolom, tipe data, primary/foreign keys, dan constraint.
> * Indexing Strategy: Kolom mana saja yang harus di-index untuk optimasi kueri baca.
> * API RESTful Contract: Daftar endpoint utama (GET, POST, PUT, DELETE) lengkap dengan contoh request payload dan response JSON. Termasuk standar error response (status code 4xx/5xx).
> * Data Integrity: Aturan normalisasi yang dipakai atau alasan kenapa memilih de-normalisasi di titik tertentu.
>
> Pastikan struktur ini siap diimplementasikan ke framework backend dan gampang dibaca oleh frontend developer.
